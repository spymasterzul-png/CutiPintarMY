# Nak menyumbang?

Buka issue atau pull request dengan penerangan ringkas. Bagi pembetulan cuti, sertakan pautan kerajaan, tarikh, negeri terlibat dan sama ada cuti asal, tambahan atau gantian. Jangan ubah jadual tanpa sumber. Jalankan `node --test`. Semak paparan mudah alih, kawalan papan kekunci dan eksport kalendar jika mengubah UI. Elakkan data peribadi dan kunci akses dalam repo.
